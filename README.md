# Tesserarius site

The presentation page of Tesserarius – Carte fedeltà, served by GitHub Pages at https://ivemberg.github.io/tesserarius/.

- Screenshots come from `docs/store/screenshots/` in the app repo, resized.
- `leather.jpg` is the CC0 `leather-pebbled` tile (ambientCG Leather037) from the app's `assets/textures/`.
- `duoworthy-tesserarius.svg` is a local copy of https://duoworthy.com/badge/tesserarius.svg, so the page makes no third-party requests.
- The privacy policy and the shop catalogue live in `ivemberg/tesserarius-catalogue`.
